# Uso de inteligência artificial

## Uso registrado nesta conversa

O assistente de IA do OpenCode foi usado para inspecionar o desenho `dev.pen`, implementar a interface React com Tailwind, integrar a API Frankfurter, ajustar o gráfico e o nome do projeto, componentizar o frontend e produzir esta documentação.

Foram consultados o desenho por meio das ferramentas do pen.dev e documentação da Frankfurter e do Tailwind por meio do Context7. Também foram executadas consultas HTTP à API e comandos de build e lint; seus resultados estão registrados nos documentos de testes.

## Responsabilidade e limites

Conteúdo gerado por IA deve ser revisado por pessoas responsáveis pelo projeto. A execução de build e consultas pontuais não substitui testes funcionais, acessibilidade, segurança ou conferência visual em diferentes dispositivos. Nenhuma validação humana adicional é afirmada neste registro.
